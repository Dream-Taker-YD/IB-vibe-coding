교사 모드: 학급 평균 차트

학생들이 백업한 JSON 파일을 여러 개 한꺼번에 골라 불러오면 학급 평균 레이더를 보여 줘요. 불러온 파일은 이 화면에서만 쓰고 저장하지 않아요.

이 링크에서는 파일 내려받기와 인쇄가 막혀 있어요. 결과 이미지는 길게 누르거나 마우스 오른쪽 버튼으로 저장하고, 백업은 복사해서 보관하세요. 인쇄가 필요하면 index.html 파일로 열어 쓰면 돼요.
